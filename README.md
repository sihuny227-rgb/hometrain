# 홈트 5종 루틴 · 휴대폰 앱 버전

준비운동 10분, 맨몸 5종 본 운동, 마무리 운동 10분을 동작 그림과 타이머로 따라 하는 앱입니다.
휴대폰 홈 화면에 설치해서 쓰는 웹앱(PWA)이라 앱스토어 없이 설치할 수 있고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 오프라인 실행과 새 버전 안내 |
| `icons/` | 홈 화면 아이콘 |

이 폴더를 통째로 인터넷 주소(https)가 있는 곳에 올려야 휴대폰에 설치할 수 있습니다. 파일을 휴대폰으로 옮겨 직접 열면 설치와 오프라인 기능이 동작하지 않습니다.

## 1. 인터넷에 올리기 (처음 한 번)

### 방법 A: GitHub Pages (무료, 계속 유지)

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 이름을 `hometrain`으로 정하고 **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file**을 누르고, 이 폴더 안의 파일과 `icons` 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://내아이디.github.io/hometrain/` 주소가 생깁니다.

저장소에는 앱 코드만 올라갑니다. 운동 기록은 각자의 휴대폰 안에만 저장되고 GitHub에는 올라가지 않습니다.

### 방법 B: Netlify Drop

1. [app.netlify.com/drop](https://app.netlify.com/drop)에 들어가 로그인합니다.
2. 이 폴더를 통째로 화면에 끌어다 놓으면 주소가 생깁니다.

로그인하지 않고 올린 사이트는 잠시 뒤 지워질 수 있으니 꼭 로그인한 상태로 올려 주세요.

## 2. 휴대폰에 설치하기

**안드로이드 (Chrome)**
1. Chrome으로 위 주소를 엽니다.
2. 화면 위에 뜨는 **앱으로 설치** 버튼을 누르거나, 오른쪽 위 ⋮ 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.

**아이폰 (Safari)**
1. 반드시 **Safari**로 주소를 엽니다. 카카오톡 같은 앱 안에서 링크를 열었다면 오른쪽 아래 메뉴에서 Safari로 열기를 먼저 누르세요.
2. 아래쪽 **공유** 버튼 → **홈 화면에 추가** → **추가**를 누릅니다.

설치한 뒤에는 인터넷이 연결된 상태에서 두 번 정도 열어 두세요. 그다음부터는 비행기 모드에서도 글꼴까지 똑같이 열립니다.

## 3. 기록 관리

- 운동 기록과 설정은 그 휴대폰 안에만 저장됩니다. claude.ai에서 쓰던 기록과는 따로 관리됩니다.
- **설정 → 기록 백업 → 파일로 내보내기**를 누르면 `.json` 파일로 저장됩니다. 아이폰은 공유 화면에서 **파일에 저장**, 안드로이드는 다운로드 폴더에 저장됩니다.
- 휴대폰을 바꾸거나 앱을 다시 설치했다면 **파일에서 가져오기**로 그 파일을 고르세요. 이미 있는 기록은 중복 없이 합쳐집니다.
- 아이폰에서 홈 화면에 추가하지 않고 Safari로만 쓰면, 한동안 열지 않았을 때 기록이 지워질 수 있습니다. 홈 화면에 설치해서 쓰세요.

## 4. 고친 버전 올리기

1. 바뀐 파일을 같은 곳에 다시 올립니다.
2. 이때 `sw.js` 맨 위의 `hometrain-v1`을 `hometrain-v2`처럼 숫자를 하나 올려서 함께 올립니다.
3. 휴대폰에서 앱을 다시 열면 **새 버전이 준비됐어요** 안내가 뜹니다. **지금 적용**을 누르면 바뀝니다. 운동 도중에 저절로 새로고침되지는 않습니다.

## 5. 컴퓨터에서 미리 보기

이 폴더에서 아래 명령을 실행한 뒤 브라우저로 `http://localhost:8080`을 엽니다.

```bash
python -m http.server 8080
```
